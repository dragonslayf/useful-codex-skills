## 8. 命令

````bash
python - <<'PY'
from pathlib import Path
import json
root=Path('/workspace/useful-codex-skills')
files=[]
for p in sorted(root.rglob('*')):
 if not p.is_file() or any(x in {'.git','dist','__pycache__'} for x in p.relative_to(root).parts): continue
 b=p.read_bytes()
 try: b.decode('utf-8'); binary=False
 except UnicodeDecodeError: binary=True
 files.append({'path':p.relative_to(root).as_posix(),'binary':binary,'size':len(b)})
print(json.dumps(files))
PY
````

说明：枚举待上传文件，排除 .git、dist 与 Python 缓存；尝试 UTF-8 解码以区分文本和二进制，输出路径及大小，不输出文件内容。

## 上传流程

通过 GitHub create_blob 上传二进制资源，再用 create_tree 建立文本及资源的完整文件树，create_commit 创建基于原 main 提交的新提交，update_ref 以预期旧提交作为检查更新 main，不强制覆盖历史。此记录随源码提交，因此最终提交 SHA 与远程核验结果在对话最终回复及本地对话日志中报告。
